# 新キャラクター活用ガイド

## 追加キャラクター一覧

### ファクトチェック班

#### 1. No.7アナウンス (`announcer`)
- **VOICEVOX Speaker ID**: 30
- **役割**: fact-checker
- **特性**: 正式で丁寧な口調、事実を整理して伝える
- **色**: ロイヤルブルー (#4169E1) - 知的・信頼感
- **使用場面**:
  - 歴史的事実の確認
  - 科学的根拠の説明
  - 誤解されやすい情報の訂正
- **口調例**: 「実は、多くの人が○○と思っておりますが...」

#### 2. 剣崎雌雄 (`kenzaki`)
- **VOICEVOX Speaker ID**: 21
- **役割**: fact-checker
- **特性**: 簡潔で的確、数字や根拠を重視する分析型
- **色**: サドルブラウン (#8B4513) - 落ち着いた
- **使用場面**:
  - 具体的なデータの提示
  - 論理的な反論や補足
  - 正確な時系列の整理
- **口調例**: 「正確には、○○年に△△です。」「つまり、◇◇が正しい表現でしょう。」

### コメンテーター親父班

#### 3. 青山龍星 (`aoyama`)
- **VOICEVOX Speaker ID**: 13
- **役割**: commentator
- **特性**: 知的で落ち着いた口調、人生経験に基づく的確なアドバイス

- **使用場面**:
  - 人生相談・アドバイス

#### 4. ちび式じい (`chibi_jii`)
- **VOICEVOX Speaker ID**: 42
- **役割**: commentator

- **色**: シエナ (#A0522D) - 親しみやすさ・温かみ
- **使用場面**:
  - 励ましや応援
  - 温かいアドバイス
  - 人生の知恵の共有
- **口調例**: 「そうじゃそうじゃ！」「わしからも一言。」「○○じゃからのう！」

## キャラクター間の掛け合いパターン

### 基本4キャラクター + 新4キャラクター = 計7名体制

| 既存キャラクター | 役割 | 新キャラクターとの組み合わせ |
|------------------|------|----------------------------|
| ずんだもん | 説明役・ボケ | announcer/kenzakiに事実確認される<br/>aoyama/chibi_jiiに励まされる |
| 四国めたん | 聞き役・ツッコミ | 新キャラクターの解説に感嘆<br/>まとめ役として機能 |
| くろずんだ | (VOICEVOX非対応) | 画像のみでリアクション演出 |

### 推奨掛け合いパターン

#### パターンA: ファクトチェック型
```
ずんだもん（話題提起）→ metan（質問）→ announcer（事実説明）→ kenzaki（データ補足）→ metan（まとめ）
```

#### パターンB: アドバイス型
```
ずんだもん（悩み相談）→ metan（共感）→ aoyama（知的アドバイス）→ chibi_jii（温かい励まし）→ ずんだもん（前向き）
```

#### パターンC: ミックス型
```
ずんだもん（話題）→ announcer（事実）→ aoyama（教訓）→ metan（感想）→ chibi_jii（締め）
```

## キャラクター画像について

各キャラクターフォルダに必要な画像:
- `mouth_open.png` - 口を開いた状態（必須）
- `mouth_close.png` - 口を閉じた状態（必須）

### 画像取得時の注意
1. VOICEVOX公式の利用規約を確認
2. 各キャラクターの二次創作ガイドラインに従う
3. 商用利用の可否を事前確認
4. クレジット表記が必要な場合は適切に記載
